# Petshop

Landing page estática feita com HTML, CSS e JavaScript. Não precisa instalar dependências ou compilar o projeto.

## Arquivos

- `index.html`: conteúdo da página.
- `styles.css`: layout e estilos responsivos.
- `script.js`: menu móvel e configuração dos contatos.

## Personalizar o contato

No início de `script.js`, preencha `whatsappNumber` com o número completo, incluindo código do país e DDD, somente com dígitos. Se preferir, preencha `contactEmail`. Também é possível informar endereço e horários.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos desta pasta para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione a publicação pela branch principal e pela pasta `/ (root)`.
5. Salve. O GitHub Pages publicará o `index.html`.

As fotografias são carregadas do Unsplash e precisam de conexão com a internet.
